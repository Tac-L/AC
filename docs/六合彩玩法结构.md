## 1. 基础规则与全域元素

### 1.1 开奖结构

- 号码范围 **01–49**，每期开出 **7 个不重复号码**。
- 前 6 个（依开奖顺序）＝ **正码**，第 7 个＝ **特码**。
- 「当期号码」＝ 7 个号码全部；「正码」＝ 前 6 个；「特码」＝ 最后 1 个。
- 资料结构：`drawNumbers[0..5]` 为正码（开奖顺序，非号码大小），`drawNumbers[6]` 为特码。

### 1.2 三种游戏场次（开奖频率）

| 场次 ID | 名称 | 一期长度 |
|---|---|---|
| `ap_lhc_1m` | 一分澳门六合彩 | 60 秒 |
| `ap_lhc_5m` | 五分澳门六合彩 | 300 秒 |
| `ap_lhc_10m` | 十分澳门六合彩 | 600 秒 |

三种场次的**玩法完全相同**，只有开奖频率不同。

### 1.3 盘口（全域赔率倍率）

页首有一个下拉选单可切 A~D 盘。**盘口不改变任何玩法或按钮，只整体缩放赔率。**

| 盘口 | 名称 | 系数 |
|---|---|---|
| A | A盘 | 1 |
| B | B盘 | 0.985 |
| C | C盘 | 0.97 |
| D | D盘 | 0.955 |

> ⚠️ **容易混淆**：这里的「A/B/C/D 盘口」是**全站下拉选单**；下面 §3.1「特码」大类里的「特码A / 特码B」是**特码专属的两组不同赔率子分页**，两者互相独立、会叠加计算。

### 1.4 波色（每个号码固定属于一色）

| 波色 | 色码 | 号码 | 个数 |
|---|---|---|---|
| 红波 | `#e3342f` | 01、02、07、08、12、13、18、19、23、24、29、30、34、35、40、45、46 | 17 |
| 绿波 | `#16a34a` | 05、06、11、16、17、21、22、27、28、32、33、38、39、43、44、49 | 16 |
| 蓝波 | `#2563eb` | 03、04、09、10、14、15、20、25、26、31、36、37、41、42、47、48 | 16 |

### 1.5 号码球图片

每个号码有一张对应美术球图：`/lhc-ball/num=01.png` … `num=49.png`（**两位数补零**）。
球图本身已含号码与波色，不需另外画色圈或数字。

### 1.6 常见判定名词（多个玩法共用）

| 名词 | 定义 | 49 的处理 |
|---|---|---|
| 大 / 小 | ≥25 为大，≤24 为小 | 49 = 和（退回） |
| 单 / 双 | 号码本身奇偶 | 49 = 和 |
| 合大 / 合小 | 十位＋个位之和 ≥7 为合大，≤6 为合小 | 49 = 和 |
| 合单 / 合双 | 十位＋个位之和的奇偶 | 49 = 和 |
| 尾大 / 尾小 | 个位 5–9 为尾大，0–4 为尾小 | 49 = 和 |
| 家禽 / 野兽 | 家禽＝牛马羊鸡狗猪；野兽＝鼠虎龙蛇兔猴 | **49 照常算输赢** |
| 波色 | 见 §1.4 | **49 照常算输赢**（属绿波） |
| 数字范围 | 01-10 / 11-20 / 21-30 / 31-40 / 41-49 | **49 照常算输赢** |

## 2. 三层结构总览

左侧（或顶部）为 **19 个大类分页**，其中第 1 个「长龙」是走势统计、**不是投注玩法**。

```
六合彩
├─ 长龙            ← 统计页，无投注按钮
├─ 特码            ← 有小类：特码A / 特码B  →  3 个折叠抽屉
├─ 正码            ← 无小类            →  3 个折叠抽屉
├─ 正特            ← 有小类：特一~特六   →  3 个折叠抽屉
├─ 特肖            ← 无小类，12 张生肖卡
├─ 正肖            ← 无小类，12 张生肖卡
├─ 一肖            ← 无小类，12 张生肖卡
├─ 一肖不中        ← 无小类，12 张生肖卡
├─ 尾数            ← 无小类，10 张尾数卡
├─ 尾数不中        ← 无小类，10 张尾数卡
├─ 特头数          ← 无小类，5 张头数卡
├─ 特尾数          ← 无小类，10 张尾数卡
├─ 半波            ← 无小类，30 张组合卡
├─ 五行            ← 无小类，5 张五行卡
├─ 总肖            ← 无小类，8 颗色块按钮
├─ 七色波          ← 无小类，4 颗色块按钮
├─ 合肖            ← 有小类：二肖~十一肖  →  12 张生肖卡（多选组合）
├─ 连码            ← 有小类：四全中~特串  →  01-49 号码（多选组合）

```

### 3.4 生肖四兄弟：特肖 / 正肖 / 一肖 / 一肖不中

四个大类**结构完全相同**：无小类，12 张生肖卡（型态 D），差别只在**判定对象**与**赔率**。

**按钮顺序（12 张卡）**：

```
鼠  牛  虎  兔  龙  蛇  马  羊  猴  鸡  狗  猪
```

每张卡内容 = 生肖名 ＋ 赔率 ＋ 该生肖的 4~5 颗号码球（号码见 §5.1）。

| 大类 | tab id | 判定对象 | 中奖条件 | 马的赔率 | 其余 11 生肖赔率 |
|---|---|---|---|---|---|
| 特肖 | `texiao` | 特码 | 特码属于该生肖 | 9.1 | 11.55 |
| 正肖 | `zhengxiao` | 6 个正码 | 有正码属于该生肖（**命中数越多派彩倍增**） | 1.1245 | 1.4891 |
| 一肖 | `yixiao` | 全部 7 个号码 | 有号码属于该生肖 | 1.1 | 1.41 |
| 一肖不中 | `yixiao-no` | 全部 7 个号码 | **没有**号码属于该生肖 | 1.54 | 1.19 |

> **为什么马不一样**：马有 5 个号码（01、13、25、37、49），其余生肖各 4 个。号码多 → 一肖／正肖／特肖较容易中，赔率低；一肖不中反向，赔率反而高。
> 49 一律照常算输赢，不为和。
