# 「简 / 专」双态切换开关 — 实现说明（交接文件）

> 本文说明本专案（娱乐城 H5）投注抬头列上那颗小小的 **简易版 / 专业版** 切换开关的完整实现方式，供其他专案直接照抄或改写。
>
> 原始程式码位置：`src/components/ModalVideoPlayer.jsx`（共 6 处，样式完全一致）

---

## 1. 视觉规格

一颗 **46 × 24** 的圆角灰底轨道（track），里面有一颗 **18 × 18** 的圆角色块（knob），色块上直接写着**目前所在的模式**：

| 状态 | 色块文字 | 色块颜色 | 色块位置 |
| --- | --- | --- | --- |
| 简易版（`simpleMode = true`） | `简` | 绿 `#22c55e` | **靠右** |
| 专业版（`simpleMode = false`） | `专` | 红 `#ef4444` | **靠左** |

⚠️ 两个容易搞反的点，移植时请特别注意：

1. 色块上的字是**「现在是什么」**，不是「点了会变什么」（`title` 提示文字才是讲点了会变什么）。
2. 预设值 `true`（简易版），所以**开关一进场是绿色、且色块在右边**。

### 色票

| 用途 | 色码 |
| --- | --- |
| 轨道底色 | `#eef2f6` |
| 轨道边框 | `1px solid #e2e8f0` |
| 色块（简易版） | `#22c55e` |
| 色块（专业版） | `#ef4444` |
| 色块文字 | `#ffffff` |

## 2. DOM 结构（只有两层）

```
<div>            ← 轨道 track：position: relative，负责尺寸、底色、边框、点击
  └── <span>     ← 色块 knob：position: absolute，负责位移、变色、显示文字
```

没有 `<input type="checkbox">`，没有伪元素，没有第三方套件。**整颗开关就是两个元素 + 一个 boolean state。**

## 3. 本专案的原始写法（inline style，可直接复制）

本专案 **完全用 inline style 写死**，`className`（`vp-f3-mode-switch` 等）只是给人看的标记，**`index.css` 里没有任何对应规则**，所以复制时不需要一起搬 CSS。

```jsx
<div
  className="vp-f3-mode-switch"
  onClick={toggleF3SimpleMode}
  title={f3SimpleMode ? '当前简易版，点击切换专业版' : '当前专业版，点击切换简易版'}
  style={{
    flexShrink: 0,
    position: 'relative',
    width: '46px',
    height: '24px',
    borderRadius: '4px',
    background: '#eef2f6',
    border: '1px solid #e2e8f0',
    cursor: 'pointer',
    boxSizing: 'border-box'
  }}
>
  <span
    style={{
      position: 'absolute',
      top: '2px',
      left: '2px',
      width: '18px',
      height: '18px',
      display: 'flex',
      alignItems: 'center',
      justifyContent: 'center',
      borderRadius: '4px',
      fontSize: '0.6rem',
      color: '#ffffff',
      background: f3SimpleMode ? '#22c55e' : '#ef4444',
      transform: f3SimpleMode ? 'translateX(22px)' : 'translateX(0)',
      transition: 'transform 0.18s ease, background 0.18s ease'
    }}
  >
    {f3SimpleMode ? '简' : '专'}
  </span>
</div>
```

state 与切换函式：

```jsx
// 一律预设简易版
const [f3SimpleMode, setF3SimpleMode] = useState(true);

// 切换时「清空两边已选点位」——与切换玩法的行为一致，避免简易版选的注单带到专业版
const toggleF3SimpleMode = () => {
  setF3SimpleMode(v => !v);
  setSelectedOdds(new Set());   // 专业版的已选点位
  setSelectedF3P(new Set());    // 简易版的已选点位
};
```

## 4. 数字是怎么来的（移植改尺寸时照这个算）

因为轨道是 `box-sizing: border-box` + `1px` 边框，绝对定位的色块是相对 **padding box**（= 46 − 2 = **44px** 宽、24 − 2 = **22px** 高）定位的：

```
位移距离 = padding box 宽 − 左右内缩 × 2 − 色块宽
        = 44 − 2 × 2 − 18
        = 22px          ← 这就是 translateX(22px) 的由来

垂直置中 = (22 − 18) / 2 = 2px   ← 这就是 top: 2px 的由来
```

所以若要改尺寸，只要维持这条式子即可，例如做成 56 × 28、色块 22：
`translateX(54 − 4 − 22) = translateX(28px)`、`top: 3px`。

---

## 5. 关键实作细节（为什么这样写）

| 做法 | 原因 |
| --- | --- |
| 用 `transform: translateX()` 位移，**不是**改 `left` | `transform` 走合成层，动画不触发 layout，在手机 WebView 上不会掉帧 |
| `transition` 同时列 `transform` 与 `background` | 位移与变色同时发生（0.18s），少一个就会「先跳位再变色」 |
| 轨道 `box-sizing: border-box` | 有 `1px` 边框，不写这行整颗会变成 48px，位移距离就要重算 |
| 轨道 `flexShrink: 0` | 它被放在 flex 抬头列里，旁边有会变长的期号／比赛名，不锁死会被压扁 |
| 色块用 `display:flex + center` 置中文字 | 单一中文字用 `line-height` 在不同机型会有 1px 误差，flex 置中最稳 |
| 色块也用 `borderRadius: 4px`（不是圆形） | 视觉上跟同一列的方形图示按钮（`.vp-close-icon` 等 6px 圆角）同一套语言 |
| `title` 属性写「点了会变什么」 | 桌机 hover 提示；手机没作用，纯粹加分 |

### ⚠️ `fontSize: '0.6rem'` 移植时请改成 px

本专案在 `src/index.css` 把根字级放大了：

```css
html { font-size: 128.6%; }   /* 全站 rem 字级整体放大 ~4pt */
```

所以 `0.6rem` 在本专案实际是 **≈ 12.3px**。搬到没有这段设定的专案，`0.6rem` 只会得到 9.6px，字会明显偏小。**建议直接改写成 `fontSize: '12px'`。**

## 6. 建议的移植版本（抽成通用元件）

原专案是 6 处复制贴上，新专案建议抽成元件。以下为等价、且已把 `rem` 换成 `px`、补上无障碍语意的版本：

```jsx
/**
 * 双态切换开关：色块显示「当前模式」，on 时靠右显示 onLabel，off 时靠左显示 offLabel。
 */
function ModeSwitch({
  checked,
  onChange,
  onLabel = '简',
  offLabel = '专',
  onColor = '#22c55e',
  offColor = '#ef4444',
  title,
}) {
  return (
    <button
      type="button"
      role="switch"
      aria-checked={checked}
      onClick={() => onChange(!checked)}
      title={title}
      style={{
        flexShrink: 0,
        position: 'relative',
        width: 46,
        height: 24,
        padding: 0,
        borderRadius: 4,
        background: '#eef2f6',
        border: '1px solid #e2e8f0',
        cursor: 'pointer',
        boxSizing: 'border-box',
      }}
    >
      <span
        style={{
          position: 'absolute',
          top: 2,
          left: 2,
          width: 18,
          height: 18,
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          borderRadius: 4,
          fontSize: 12,
          color: '#fff',
          background: checked ? onColor : offColor,
          transform: checked ? 'translateX(22px)' : 'translateX(0)',
          transition: 'transform 0.18s ease, background 0.18s ease',
        }}
      >
        {checked ? onLabel : offLabel}
      </span>
    </button>
  );
}
```

用法：

```jsx
const [simpleMode, setSimpleMode] = useState(true);

<ModeSwitch
  checked={simpleMode}
  onChange={next => { setSimpleMode(next); clearSelections(); }}
  title={simpleMode ? '当前简易版，点击切换专业版' : '当前专业版，点击切换简易版'}
/>
```

> 改用 `<button>` 时记得 `padding: 0`，否则浏览器预设 padding 会把尺寸撑开。

```css
.mode-switch {
```

```js
document.querySelector('.mode-switch').addEventListener('click', el => {
  const box = el.currentTarget;
  const simple = box.dataset.mode === 'simple';
  box.dataset.mode = simple ? 'pro' : 'simple';
  box.querySelector('.mode-switch__knob').textContent = simple ? '专' : '简';
  box.title = simple ? '当前专业版，点击切换简易版' : '当前简易版，点击切换专业版';
});
```

## 9. 移植检查清单

- [ ] `fontSize` 从 `0.6rem` 改成 `12px`（除非你的专案也放大了根字级）
- [ ] 确认外层是 flex 容器，且开关有 `flex-shrink: 0`
- [ ] 确认预设值是 `true`（简易版 = 绿色 + 靠右）
- [ ] 切换时要不要清空使用者已选的资料（本专案会清空，避免脏资料带过去）
- [ ] 若改用 `<button>`，记得 `padding: 0`
- [ ] 若改尺寸，用第 4 节的公式重算 `translateX` 与 `top`
